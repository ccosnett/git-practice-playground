# Git Practice Playground

A small sandbox for practicing branches, rebases, merges, and commits.

## Try it

1. Create a branch: `git switch -c add-your-name`
2. Edit `contributors.txt` and commit your change.
3. Switch back to `main`, make another commit, then rebase your branch: `git rebase main`.
4. Resolve a conflict, continue the rebase, and compare the history with `git log --oneline --graph --all`.

Nothing here is important. Break it, reset it, and start over.
